# AI Experience Agent Worklog

> MoneyTalk의 AI 기능을 채팅 중심에서 사용자가 바로 체감하는 인사이트/정리 중심으로 옮기기 위한 단계별 작업 문서.
> 한 번에 화면 구조를 갈아엎지 않고, 각 단계마다 작은 변경과 검증을 거친 뒤 다음 단계로 이동한다.

## 작업 기준

- 무료 기본 경쟁력인 SMS 자동 기록, 기본 분류, 홈/가계부 통계는 유지한다.
- 채팅 기능은 즉시 삭제하지 않고, 사용성 데이터와 대체 화면이 준비될 때까지 보조 진입점으로 낮춘다.
- AI 체감은 사용자가 질문을 작성하는 방식보다 앱이 먼저 제안하는 정리/인사이트에서 만든다.
- 전면/리워드 광고는 사용 흐름을 막는 느낌이 강하므로 기본 수익화 축으로 삼지 않는다.

## 단계별 방향

1. AI 탭의 문구를 상담/채팅 중심에서 인사이트 확인 중심으로 바꾼다.
2. 홈 또는 AI 탭에 "확인 필요한 항목", "반복/구독 지출", "예산 초과 가능성" 같은 정리 카드 후보를 설계한다.
3. 기존 채팅은 "직접 물어보기" 보조 진입점으로 낮추고, 자주 쓰는 질문은 카드/버튼 액션으로 전환한다.
4. Gemini 호출 비용이 큰 자유 채팅보다 로컬 집계 기반 인사이트를 우선 사용하고, AI는 설명/요약에만 제한적으로 쓴다.
5. Plus 후보는 기본 기록/분류 제한이 아니라 광고 제거, 고급 리포트, 반복 지출 탐지, 자동 백업 편의 기능으로 둔다.
