## 라우팅 모델

루트 문서는 판단과 라우팅을 담당한다.
도메인/기능/서브모듈 문서는 선택된 뒤의 실행 상세와 현재 코드 구조를 담당한다.
공통 작성 규약이나 빌드 차단 규칙처럼 작업 전 반드시 피해야 할 규칙은 `AGENTS.md` 또는 루트 공통 문서에 두고, KB에는 구현 위치와 링크만 둔다.

## 작성 원칙

- 현재 코드와 실제 diff로 확인한 사실만 적는다.
- 없는 문서와 없는 코드 경로를 추정해서 링크하지 않는다.
- 도메인 구현 지식, 기능 흐름, 서브모듈 공통 지식을 섞지 않는다.
- 상세 구현은 하위 문서에 두고, 루트 README는 라우팅과 인덱스 역할만 한다.
