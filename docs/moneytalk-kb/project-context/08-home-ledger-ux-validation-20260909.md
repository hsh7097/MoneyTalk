# 홈·가계부 후속 UX 검증 기록

사용자의 추가 요청을 `codex/finance-ui-refresh`에서 구현하고 최종 작업 트리를 검증했다. [이전 금융 UI 검증](07-finance-ui-validation-20260908.md) 이후의 기록이며, 이전의 철회된 홈 재설계를 다시 적용하지 않는다. 홈 그라데이션과 월 지출 바로 아래 차트 순서를 보존했다.

## 구현 범위

| 기능 | 결과와 보존 경계 |
|---|---|
| 홈 다크 대비 | 보조 글자와 고정 예상 카드의 제목·내용 대비를 보정했다. |
| 고정 예상 문구 | 행마다 관찰한 개월 수를 표시하고, 예측의 불확실성과 근거 내역 이동 안내는 한 번만 표시한다. |
| 미정리 거래 | 설정의 건수와 직접 정리 목록이 같은 가시성 필터를 사용한다. 기존 거래 편집과 같은 거래처 적용을 재사용하며 자동 분류는 별도 동작이다. |
| 차트 범례 | 연도를 생략하고 월만 표시한다. 비교할 연도와 회계 기간 계산은 그대로다. |
| 주간 소비 카드·근거 | `내 소비 한눈에`에 테두리를 적용하고 `최근 7일 소비`와 `이전 7일 소비`의 금액을 강조한다. 기본 폭에서는 가로, 큰 글자·좁은 폭·긴 금액에서는 세로로 배치한다. 두 기간 및 늘어난 카테고리에서 정확한 거래 근거를 연다. |
| 주간 고정비 제외 | 문구는 `고정 지출 제외 · 기록 기준`이다. 주간 합계·증감·근거 목록에서 고정 거래를 제외하며 월 전체 합계·누적 차트·예산 계산에는 이 제외 규칙을 확대하지 않는다. |
| 홈 고정 예상 위치 | 오늘 거래 뒤, 홈 최하단으로 이동한다. 예상 결제를 실제 소비에 새로 적재하지 않는다. |
| 수입·지출 색 | 라이트·다크와 홈 그라데이션에서 수입은 빨강, 지출은 파랑을 쓴다. 통계 제외 상태 태그를 유지하며 브랜드 액션·오류·비교선 색은 금액 의미와 구분한다. |
| 가계부 스크롤 | 큰 제목·월 요약은 스크롤과 함께 접히고 `목록·달력·필터`는 한 줄로 남는다. 적용된 필터를 다시 열 수 있고 X만 초기화한다. 탭 재선택으로 상단을 복원하며 달력에서 검색 시 목록을 보여 주고 검색 종료 시 달력을 복원한다. |
| 차트 날짜 선택 | 탭 또는 길게 누른 뒤 드래그하면 가이드와 점이 이동하고 실제 날짜·기간 일차·노출한 비교선의 원본 누적 금액을 표시한다. 선택은 손을 떼어도 유지하며 닫기·월·활성 페이지 변경으로 해제한다. 오늘 이후 당월 금액이나 짧은 전월의 말일 이후 값을 만들지 않는다. 과거·평균 값이 있는 미래 일차는 조회할 수 있다. |

차트 선택은 홈에서 활성화한다. 카테고리 상세 등 기존 호출부의 동작과 부모의 일반 세로 스크롤·월 넘기기를 보존한다. 좌표 계산은 현재 사용 중인 Vico `2.0.0-alpha.28`의 `LineCartesianLayer` 소스와 대조했다([공식 Maven 소스](https://repo.maven.apache.org/maven2/com/patrykandpatrick/vico/core/2.0.0-alpha.28/core-2.0.0-alpha.28-sources.jar)). 라이브러리 버전·빌드 설정·DB 스키마는 변경하지 않았다.
